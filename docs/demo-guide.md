# Advanced demonstration guide

Start the application with `powershell -ExecutionPolicy Bypass -File .\scripts\run.ps1`, then open http://localhost:8080/securefiles/login. Use separate browser profiles for Anu, Bala, Chitra and an administrator. Public registration creates ordinary users; the README gives the explicit administrator bootstrap command. Use a real unsigned, unencrypted PDF of at most 40 pages.

1. **Anu uploads a confidential PDF.** Upload the PDF, open its details, choose Confidential and enable listing in the authenticated request catalogue. Save. Explain that only deliberately listed metadata is visible to other registered users.
2. **Bala requests access.** Open Request Catalogue as Bala, enter a reason and submit. Show My Requests as PENDING. Anu opens Notifications and Requests Received, chooses Approve with Settings, selects View once and reviews the exact summary before confirming. This grants one session, zero downloads and no resharing.
3. **Bala verifies an OTP and views.** Open Shared with Me → View Access and Allowed Actions → Verify OTP to View. In default LOCAL mode the screen says no email was sent; open My Local Mailbox and copy the newest matching six-digit code. Verify and start the viewer within two minutes. Show the identity/time watermark. Refresh: the same session is reused, with one view consumed rather than one per page.
4. **Bala tries Share.** The application displays exactly: “This file cannot be shared. The file owner has denied resharing permission.” A direct transfer request is also denied. Explain that the original PDF is not sent by the viewer, but screenshots/browser capture remain possible.
5. **End the session.** Click Close Viewer or wait for its ten-minute maximum lifetime. A new initiation is denied because the one view has already been used. Closing does not refund a view. Expiry, access hours and revocation still apply to all page requests.
6. **Chitra receives two downloads.** For a separate NORMAL PDF, Anu uses Custom with downloading enabled, limit 2, viewing disabled and resharing denied. After confirmation, Chitra starts two transfers; the third is denied. Each PDF has a separate personalized watermark. Edit the policy without changing its limit: consumed counts remain. A confidential PDF instead requires a fresh OTP per transfer and enforces the resend cooldown.
7. **Controlled onward sharing.** For a separate file, Anu enables resharing for Bala with a limited ancestor budget. Bala grants narrower access to Chitra, who can delegate only if enabled and only to the third recipient level. A descendant's use consumes every applicable ancestor budget. Sharing back to the owner/ancestor, exceeding ancestor expiry or broadening disabled actions is rejected. Anu's recipient table shows parent relationships and usage; revoking the parent blocks the whole branch.
8. **Versions.** Anu uploads a new immutable version from Version History. Existing counts do not reset. A latest-active grant opens the new version for a new operation; an existing viewer remains pinned to its old version. A specifically pinned grant stays on its selected version. Archive the old version and show that its existing viewer can no longer fetch pages.
9. **Alerts and audit.** Repeated denied actions trigger threshold-based alerts. Admin opens Security Alerts and acknowledges or resolves one. Owners see only alerts concerning their files. Admin opens Audit Verification and Checkpoints, verifies the chain and exports a protected checkpoint. Explain that database-only rewrites need external checkpoints to detect and server/secret compromise remains outside the guarantee.
10. **Review the implementation.** Show PermissionEngine, the FileVersion model, the atomic count reservation, HMAC OTP verifier, PDF worker bounds and audit canonical encoding. Use the actual results in test-cases.md; do not claim a security certification or copying prevention.

All expiry inputs and displayed instants use UTC. Daily windows use their explicitly named timezone; starts are inclusive, ends exclusive, and overnight windows intersect with every ancestor window. India time is UTC+05:30. Stop cleanly using `powershell -ExecutionPolicy Bypass -File .\scripts\stop.ps1` in another terminal before rebuilding.
